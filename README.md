# Suman Portfolio

A premium, modern portfolio website showcasing the skills, experience, and projects of Suman, a passionate developer from Kolkata. This website is built with a focus on aesthetics, responsiveness, and clean code.

## 🚀 Live Demo
You can view the live website at: [https://github.com/SumanCH8514/Portfolio_Website](https://github.com/SumanCH8514/Portfolio_Website)

## ✨ Features
- **Modern Glassmorphism Design**: Elegant UI with frosted glass effects and vibrant background blobs.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- **Interactive Elements**: Dynamic text animations using Typed.js and smooth hover effects.
- **Project Showcase**: Detailed view of featured projects with category filtering.
- **Experience Timeline**: A visual professional journey from internships to freelance work.
- **Contact Integration**: Direct WhatsApp chat and email integration.
- **Clean Architecture**: Organized file structure for easy maintenance.

## 🛠️ Technology Stack
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Libraries/Tools**:
  - [Typed.js](https://github.com/mattboldt/typed.js/) (Dynamic typing animation)
  - [Font Awesome](https://fontawesome.com/) (Iconography)
  - [Google Fonts](https://fonts.google.com/) (Inter & Poppins)
